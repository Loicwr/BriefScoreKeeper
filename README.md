
# 🏆 Score Keeper

Bienvenue sur **Score Keeper**, une petite application web ludique pour suivre le score d’un jeu entre deux joueurs.  
Développée avec du JavaScript pur, cette app permet d'ajouter des points, de définir un score à atteindre, et de réinitialiser la partie facilement.

## 🎯 Objectif du projet

Ce projet a été conçu pour :

- Créer un outil simple de gestion de score en temps réel  
- Permettre l’interaction dynamique entre plusieurs éléments HTML avec JavaScript  
- Mettre en pratique la gestion d’événements, de conditions, et de styles dynamiques  
- Offrir une base réutilisable pour d'autres jeux à score  

## 💻 Technologies utilisées

- HTML5  
- JavaScript (vanilla)  
- CSS3 via SASS (fichier compilé dans main.css)  

## 🧠 Fonctionnalités clés

- Boutons pour incrémenter le score du joueur 1 et du joueur 2  
- Choix du score maximum pour remporter la partie  
- Affichage automatique du gagnant avec message et mise en forme  
- Réinitialisation de la partie à tout moment  
- Blocage de la partie une fois le score max atteint  

## ⚙️ Fonctionnement

- Chaque joueur clique sur son bouton pour ajouter un point  
- Lorsque l’un atteint le score maximum, la partie s’arrête  
- Un message indique le gagnant et les scores sont stylisés  
- Le bouton **Reset** permet de recommencer une nouvelle partie  

## 🚀 Mise en route

1. Télécharge ou clone le projet  
2. Ouvre simplement `index.html` dans un navigateur moderne  
3. Joue une partie et amuse-toi !

Aucune installation ou dépendance externe n’est nécessaire.
